# 💀 SHADOW_GRIMORIO (v1.0-Beta)

ShadowGrimorio es un Sistema Operativo de Sombras diseñado para la orquestación de agentes inteligentes, automatización de flujos de trabajo y gestión de soberanía digital desde entornos limitados (Android/Termux).

## 🌌 Características Principales

- **Oráculo Spica**: Interfaz conversacional asíncrona basada en LLMs (Groq/Llama 3) para el control total del sistema.
- **Arquitectura Somática**: Gestión de agentes autónomos (Void_Hunter, Janitor, Explorer) mediante un gestor de procesos ligero.
- **Espejo Dual**: Sincronización híbrida entre base de datos local (SQLite) y nube (PostgreSQL/Neon).
- **Ghost Shell**: Entorno de ejecución seguro con persistencia cifrada y limpieza de rastros.
- **Optimizado para Mobile**: Diseñado específicamente para funcionar en dispositivos de bajos recursos mediante una TUI robusta.

## 🛠️ Tecnologías

- **Lenguajes**: Python 3.13+, C++ (Hardware Bridge).
- **Interfaz**: Textual (TUI Framework).
- **Base de Datos**: SQLAlchemy + PostgreSQL/SQLite.
- **Infraestructura**: GitHub Actions (para tareas pesadas).
