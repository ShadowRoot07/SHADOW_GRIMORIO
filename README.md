# 💀 SHADOW_GRIMORIO (v1.0-Beta)

**"Digital Architect of the Void. Build in the shadows, sync with the stars."**

*Shadow_Grimorio es un orquestador de inteligencia artificial y soberanía digital diseñado para operar en entornos de alta restricción (Android/Termux). No es solo una aplicación; es un Sistema Operativo de Sombras que fusiona la potencia de los LLMs modernos con una arquitectura de datos híbrida y resiliente.*
## 🌌 Arquitectura del Sistema
1. 🧠 Oráculo Spica (Neural Link)

Interfaz conversacional asíncrona optimizada para el control total del enjambre.

- Motor: Llama-3 (Groq API) con gestión de contexto técnico persistente.

- Capacidad: Registro de hechos en tiempo real y memoria semántica sobre el stack tecnológico del usuario.

2. 🔄 Protocolo de Espejo Dual (Dual-Sync)

Sincronización robusta con integridad referencial estricta.

- Local: SQLite (Capa de baja latencia para movilidad).

- Remote: PostgreSQL / Neon (Capa de respaldo en la nube).

- Mecánica: Sincronización jerárquica basada en timestamps para asegurar la persistencia de "recuerdos" e hitos de desarrollo.

3. 🛡️ Ghost Shell & Seguridad

Entorno de ejecución diseñado para proteger la huella digital.

- Cifrado: Implementación de Master Key para persistencia de secretos.

- Burn-Protocol: Limpieza automática de rastros de sesión y archivos temporales.

4. 🚀 Gestión del Enjambre (Agent Manager)

Control de procesos ligeros para agentes especializados:

- Ghost_Coder: Asistente de desarrollo integrado.

- Bruma_Sync: Guardián de la sincronización en segundo plano.

- Survival: Monitoreo proactivo de recursos (batería/RAM) en dispositivos móviles.

## ⚡ Instalación y Uso

**Protocolo de Despliegue Rápido**

```bash
# Clonar el núcleo
git clone https://github.com/ShadowRoot07/SHADOW_GRIMORIO.git
cd SHADOW_GRIMORIO

# Configurar entorno
pip install -r requirements.txt
chmod +x shadow

# Inyectar en el sistema (Global Access)
ln -sf $(pwd)/shadow $PREFIX/bin/shadow
```

* **Comandos del CLI (shadow)**

- Desde cualquier ubicación en tu terminal:
    * shadow ui: Lanza la Matriz Visual (TUI).
    * shadow ask [agente] "[query]": Consulta directa al Oráculo.
    * shadow status: Verifica la salud de los agentes en las sombras.
    * shadow kill: Aniquila todos los procesos del enjambre.
